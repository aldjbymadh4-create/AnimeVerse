# AnimeVerse — بداية المشروع
هذا إصدار بداية لمشروع AnimeVerse مبني كـ Web App / PWA.
- يعمل من المتصفح.
- متجاوب للجوال والكمبيوتر.
- فيه Manifest وService Worker لتثبيته على الشاشة الرئيسية عندما يدعم المتصفح ذلك.
- التصميم مستوحى من الصور المرجعية التي أرسلها صاحب المشروع.
- شعار المشروع محفوظ داخل assets/logo.png.

## التشغيل
افتح index.html في بيئة استضافة ويب أو شغّله محليًا عبر خادم محلي.
مهم: ميزة التثبيت وService Worker تحتاج عادةً HTTPS عند النشر (أو localhost أثناء التطوير).

## الخطوة التالية
ربط تسجيل الدخول، قاعدة البيانات، المستخدمين، الحلقات المرخصة، النقابات، الدردشة، الفعاليات، الإشعارات ولوحة الإدارة بواجهة خلفية حقيقية.
